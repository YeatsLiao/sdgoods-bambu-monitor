以下 1–4 已进入 0.3.3 候选，第 5 步的软件渲染和容量检查通过；真实内存/性能及第 6 步的真机验收仍待完成，不能提前标记通过。唯一当前基准是 [第一批规范](../design/batch-01/SPEC.md)。

2. 页面映射：普通 AMS 与 HT 分组，第三组集中外置 + HT；删除第二页外置摘要与旧的重复外挂独立页。多盒/无盒/插拔按实际拓扑生成，保持逻辑页面身份。
3. 素材准备：04 猫咪首页、探头 AMS、外置/HT 和详情角色必须符合原型。为场景准备型号文字锚点；不再接受方块猫或过小图标作替代。素材缺失单独列出，先补素材再说还原完成。
4. 第一批 01–06 按四页逐款还原；型号和实时值为程序文字，不烘焙进整图。原型页号旧标记和第二页旧外置行按 SPEC 覆盖。所有样式共享数据与后台。
5. 完成 24 页中文/英文、未知值、长型号、HT、外置、多盒及插拔的 LVGL 验证，检查官方应用包容量和内存；用真实截图同数据逐页比较。
6. 重新编译后用 COM6 真机验收角色、裁切、型号和交互；验收记录必须明确来自设备还是软件渲染。第二、三批按相同四页规则后续补齐，不提前宣称通过。

当前工程维持标准 idf.py build / merge-bin / -p COM6 flash，只有一个 build 目录、一个应用和 18 款可切换皮肤。历史分批缓存收在 build/history，不作为开发入口。本轮候选版本为 0.3.3，构建和实际检查结果见验证状态。
