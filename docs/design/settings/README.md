# 共享设置：当前要求

当前交互：应用设置 → 外观与语言 / 熄屏与提醒 / 网络与打印机。官方下拉管理亮度、声音和退出。待机为永不/1/5/15 分钟，打印常亮、完成亮屏、异常亮屏独立设置；首次触摸只唤醒，后台继续监控。

v0.3.9补充：详情页圆形设置按钮与齿轮共用圆心，视觉与点击位置一致。设置各级页面中部右滑、左上箭头或短按电源键均逐级返回，应用设置返回原详情页。配网中先异步取消再返回；选肤页左右滑动继续切换皮肤。拖动不可误触点按，顶部下拉和唤醒首触不触发返回。实现与验证见 [0.3.9记录](../../verification/reports/settings-back-0.3.9.md)。

皮肤选择一屏一款；主屏中部静止长按 700 ms 或从外观与语言进入。左右滑动实时预览，不提前写入设置；勾选确认，叉号/电源键取消。操作条空闲 3 秒隐藏，首次点按仅唤出；语言单独一项。当前 v0.3.3 保留并回归检查了这套实现，但仍需真机操作验收。

图标应使用统一线宽和比例，并具有清楚语义：调色盘、铃铛、Wi-Fi、时钟、太阳（打印常亮）、完成勾选、异常警告、语言地球。不能混用简陋打印机符号代替常亮含义。
