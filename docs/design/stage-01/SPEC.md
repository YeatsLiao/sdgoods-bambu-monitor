# 第一批还原规范

本规范更新于 2026-11-05，以用户最新真机反馈为准。视觉目标由同目录四张参考图和本规范共同定义；第二页/第四页已更新为四页体系；所有示意读数仍以真实遥测为准。

## 页面与数据职责

1. 首页：打印机型号、状态、进度、剩余时间、喷嘴/热床读数与主题主体。型号是动态文字层；X1C/H2D/P1S 是打印机型号，不是 AMS 名称。
2. AMS：只显示普通 AMS 家族（含可识别的 Lite/2 Pro）料槽、类型、颜色、余量、活动槽及该盒的真实温湿度。盒子标题按类型 + 用户可读序号显示，例如 AMS 1、AMS 2 Pro 1；不能用 X1C/H2D 替换盒子标题。此页不再展示外置 TPU 摘要。
3. 外置 + HT：普通外置料架作为紧凑独立上区，HT 单槽作为主卡片下区；HT 读数包括当前耗材、是否使用、已知余量、真实仓温、真实湿度、烘干状态与剩余时间。普通外置料架不能借用 HT 温湿度。没有可靠字段统一显示 --。
4. 打印详情：当前层/总层、喷嘴/热床当前与目标、腔温、速度、风扇；保留本款角色和卡片风格，显示真实型号并提供齿轮入口。

通常“1 台普通 AMS + 外置 + 1 台 HT”对应四个物理页。多个普通 AMS 在第二组顺序扩展；多个 HT 在第三组内按逻辑序号分页，普通外置摘要只出现一次，不复制到每个 HT 页。没有 HT 时第三组可以只显示外置；只有 HT 时第三组只显示 HT；两者均没有则跳过该组，不编造设备。没有普通 AMS 则跳过第二组。页码/页点由真实页面生成，插拔时尽量按组 + 单元身份保持当前位置。

## 型号与名称

型号读取方案见 [MQTT 型号规则](../../notes/architecture.md)。优先采用可信 print.printer_type；订阅成功后通过 info/get_version 的主机 ota 模块补充 product_name/可识别 hw_ver。型号、设备昵称、耗材盒类型是三个概念。不能承诺所有固件提供自定义昵称，不能由访问码、IP、未核对的序列号前缀猜型号。未识别到时显示 Bambu 或 --，不伪装成 P1S。

01/02/06 按原型顶栏显示型号；03/04/05 按插画上的打印机铭牌/面板锚点显示，必要时以小标签补充，不能遗漏，也不能把动态型号烘焙进位图。长型号须适配可读宽度，不裁切或换成内部代码。详情状态标识里的“型号 · 状态”也应动态。

## 猫咪监工的硬要求

- 首页：可爱黑猫 + 橙红安全帽 + 右侧打印机，保持脸、眼睛、胡须、猫尾和动作；打印机上有型号文字位。不得以另一种简陋符号替代角色。
- AMS：可爱猫咪从浅色料仓卡片上缘探头，爪子搭在边框上；猫与卡片是完整构图，不是角落里的微型图标。
- 外置 + HT：沿用同一只猫探头，HT 主卡片、外置上区的颜色与线条保持同主题。
- 详情：沿用原型猫头/安全帽角色与浅黄卡片。旧版 ui_monitor_design.inc 中的 cat_badge 方块画法已被用户明确否定，不能再当成“已还原素材”。
- 运行素材须从已确认角色准备独立透明插画，不将整张概念图当实时背景。缺少合格素材就标记缺失，不以程序方块临时图冒充完成。

## 其余五款必须保留的差异

01：黑色大字、珊瑚强调、侧向料轴、细分隔网格。02：暖白点阵、黑底、点线列表，不能仅换配色。03：绿底像素打印机、像素边框和分段指示。05：月亮、窗、灯、打印机与料轴夜景，桃金数字/紫色强调；未知余量的柱保持空。06：紫色系、彩色料轴和分区色卡，禁止只有四条无结构色线。

## 未知值与真实性

缺失值显示 --，真实有效 0 才显示 0。15:10 的外挂 TPU 0% 不能据此判定确实空料；确认该设备的余量字段语义前按未知处理。湿度分类等级不能标成 %RH。型号应答不能刷新打印遥测时间或通过配对有效性验证。活动槽仅以真实活动身份标记，不能在外置和 HT 同时宣称当前使用。

360×360 圆屏逐款检查字号、角色比例、长型号、当前/目标温度、四/五位层数、中英文和安全区。控制中心不重做；长按选肤、返回、待机继续遵守共享设置规范。

## 验收门槛

先完成可靠型号字段与四组分页，再完成合格角色素材和锚点，随后逐款对照四张当前原型输出程序预览。至少用同一组真机数据核对 24 个中文页，并覆盖英文、未知值、无 AMS、HT 单槽、多盒和插拔。编译、字形与包体通过只算工程检查；必须将真实设备截图与原型并排检查后，才能标为还原通过。
