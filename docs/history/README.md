# 历史资料：不作为当前原型

- [records](records/)：迁移前的设计决策、旧开发计划和素材说明。
- [design](design/)：旧设置流程、实现截图和生成提示词。
- [verification](verification/)：过去各批次/候选版本的容量与验证记录。
- [releases](releases/)：冻结的软件渲染帧，原样保留。
- [assets](assets/)：被新资源替换的编码、字体副本，按哈希保留。
- [迁移清单](migration-20261105.json)：迁移前媒体哈希与旧路径到新路径映射。

旧报告中的“通过”仅代表当时报告所列检查，不是用户对当前 UI 还原的认可。当前资料从 [第一批入口](../design/batch-01/README.md) 和 [待修状态](../verification/CURRENT-STATUS.md) 查看。

历史原型、提示词、旧报告与旧资源允许Git跟踪；releases批量冻结帧由完整私有快照保存。具体范围、恢复与校验见 [收尾记录](../verification/reports/closeout-0.3.9.md)。原有历史媒体路径保持不变。
