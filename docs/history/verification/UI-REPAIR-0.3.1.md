# 第一批与共享设置原型还原 v0.3.1

依据 docs/design/batch-01 三张页面原型、settings/settings-flow.png 以及 device/screenshots 中用户提供的四张真机截图，重做第一批 01–06 的概览、AMS、详情和全部皮肤共用的设置页。07–18 仍保留先前监控布局，18 款都包含在同一标准 build 工程中。

第一批使用独立构图、大字号粗体、点阵数字、透明独立场景、侧向/立式料轴、分款列表/卡片。设置使用浅色卡片、线条图标、独立开关、配网引导与双缩略图选择。当前后台未提供型号，界面使用 BAMBU / 拓竹，不写死原型里的 P1S。概念图仍用于视觉参考，静态装饰与真实数据分开绘制。

验证：ESP-IDF 5.5.5 标准 build 编译与 merge-bin 成功，合并文件逐段匹配 flasher_args.json；官方 pack_app 校验通过。82 个官方平台文件与 radio 逐字节相同。实际 LVGL 渲染覆盖 108 个常规中英页面和设置、未知数据、100% 进度、长层数、未知余量、AMS HT 单槽、外置料及截图数值回放。设置入口、返回、唤醒首点不透传、皮肤应用与首尾循环、语言切换、0/1/5/15 分钟熄屏及三个独立开关均通过本机断言检查。

纯应用为 2,786,224 字节（2.657 MiB），官方上限 3,040,870 字节，剩余 254,646 字节。原先字体扫描把注释与未使用模板字计入子集；现只收集实际 UI 字符串，中文字表 187 字，五款文字字体均含所需 193 个非 ASCII 字符。完整固件仍为 3,219,456 字节，包含地址填充，不属于官方应用包大小。

当前产物：build/sdgoods-bambu-monitor-full.bin；官方应用包 dist/BambuMonitor_app.bin；SHA-256、容量和合并内容见 ui-repair-0.3.1.json。仍按根 README 的 idf.py build / merge-bin / -p COM6 flash 使用，不分批次构建。

本轮未连接设备烧录，图像为实际程序的软件渲染，不能作为触摸流畅度、颜色、内存与真实设备运行验收。新固件应烧录后用根目录串口截图.cmd 再抓同页核对。原真机照片、原概念图和旧版本快照均未覆盖，新生成原图和字体已归档到 docs/assets。
