# 设置图标与一屏一皮肤选择 v0.3.2

设置页图标统一为 24 单位、2 px 圆头线条：外观为调色盘、提醒为铃铛、网络为 Wi-Fi、自动熄屏为时钟、打印时常亮为太阳、完成为勾选、异常为警告、语言为地球。原反馈截图保存在 docs/assets/references/settings-v0.3.1-feedback.png。

主屏中部静止长按 700 ms 进入选肤；位移超过 12 px、非主屏、顶部系统区域、控制中心打开或唤醒首触均不触发。第一轮长按松手不透传。左右拖动达到 48 px 时即时切换候选，单次手势在相邻皮肤中预览，可反向拖回，01–18 首尾循环。右下勾选保存，左下叉号/电源键取消，返回入口及原页码。设置中的外观与语言页独立提供选肤入口和语言行。

预览由实际监控主屏绘制函数直接渲染当前状态，临时候选 ID 不覆盖已保存皮肤；仅确认时写入 NVS。实时状态每 500 ms 继续刷新。操作条在滑动时及空闲 3 秒后隐藏，完整展示主屏；隐藏后的首次点按仅唤出操作条，防止盲点确认。待机与打印常亮设置照常生效，首次触摸只唤醒。

本机验证已通过：700 ms 阈值、位移后回原点不误触、长按松手落在确认区域不提交、滑动中即更新与反向、首尾循环、确认/取消、保存失败保留候选、语言切换、原页码、控制中心/顶部区域隔离、预览中 37% 状态更新、预览待机及唤醒首触。中英 18 款预览主内容区与实际主屏逐像素比较通过（排除选择控件和导航区域），并输出 108 个常规页面和 72 个选肤帧。五款文字字体覆盖全部 200 个非 ASCII 界面字符。

ESP-IDF 5.5.5 标准 build 编译、merge-bin 组件校验、官方应用包校验通过；官方层 82 文件与 radio 逐字节一致。当前 app 为 2,795,712 字节（2.666 MiB），官方上传余量 245,158 字节，仍包含全部 18 款。完整固件 3,219,456 字节。产物在标准 build 目录和 dist/BambuMonitor_app.bin；哈希与参数见 settings-picker-0.3.2.json。
