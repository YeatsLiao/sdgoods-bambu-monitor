- [atlases](atlases/)：独立插画源图，不包含实时数据。

- [fonts](fonts/)：字体源、当前生成物与许可。
- [references](references/)：用户反馈和外部项目参考。
- [旧资源](../history/assets/)：被替换的编码/字体按哈希保留。
