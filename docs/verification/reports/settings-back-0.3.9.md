# 设置按钮居中与右滑返回 0.3.9

## 行为

详情页设置按钮统一为29px圆形底按钮。齿轮环、八个齿、按钮圆心均为(287,65)，使用几何绘制避免字体侧边留白和基线造成偏移。点击目标以同一圆心扩展至22px半径；第三批删除原来独立偏移的底圆，18套共用绘制与点击定义。

应用设置、外观与语言、熄屏设置、网络与打印机页面支持中部右滑返回一级；应用设置返回进入设置前的详情页。起手纵坐标81–314，右移超过48px，横移超过纵移的两倍才触发。一次手势只返回一级；点箭头和短按电源键继续有效。

拖动超过12px后，本次触摸不再当作点击，即使拖回起点也不误触。手势期间被控制中心或忙碌状态接管，就不再触发应用导航；熄屏后的首次触摸只唤醒。选肤页左右滑动继续切换候选，不改为返回。

配网页复用现有 `ui_monitor_back`：配网中先请求后台取消，等待服务切换结束再返回设置；网络忙碌期间不额外提交手势动作。
