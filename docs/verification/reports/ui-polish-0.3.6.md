# 18套细节排查与修复：0.3.6

依据用户本轮三张批注图检查全部18套。原型不覆盖，运行截图单独保存。新公共几何位于 main/apps/ui_monitor_layout.inc；各款保留原有场景、配色和绘制风格。

## 已修改

- 层数两侧数字和斜杠分开布局，按实际字宽选择同档字号，保留明确间距；点阵款仍用像素数字。共98种长短/未知数字组合验证。100%进度也按圆弦宽度整体选字号，保持数字与百分号基线，避免分别缩小。
- 详情卡片统一内收至132×48、两列对称，底部卡角进入6px圆形安全区；HT主卡内收，干燥胶囊收窄。场景/背景仍保留原型出血。
- 第二组装饰按统一标题盒等比适配，从外置与HT之间移至标题区；标题、状态、齿轮和角色分区，齿轮触摸区继续避开官方顶部区域。
- 竹叶替换为独立透明填色素材，删除交叉直线竹架。原图与完整提示词见 [素材记录](../../history/design/batch-02/bamboo-polish-20261105.md)。
- 风扇图标改成一致的三叶曲线图形，图文按实际宽度成组居中；详情字段与卡片共用基线。
- 外置料轴与HT图形中心对齐，文字列起点对齐；使用状态移到外置标题同一行，给长材质留足宽度。活动AMS行优先保留完整材质与百分比，将使用标记放到原小条位置。
- 夜班料柱略加宽、中心不变，PETG-CF完整显示。离线/过期提示进入既有状态栏，不再压温湿度；缩短两条英文设置提示，保持原意。

全部18款×四页×中英两语言共144个基准页，并覆盖长时间、长型号、百万层数、100%余量/风扇、最高温度、PETG-CF、第4活动槽、AMS 2 Pro、离线首页/AMS/HT/详情等场景。原有长按选肤、实时预览、确认/取消、语言、待机与唤醒断言通过。

累计137,775次文字绘制，零省略截字。卡片/HT圆角6px安全区和98种独立斜杠组合断言通过；压缩图片C解码边界检查通过。此结果覆盖测试输入，不能承诺任意未知设备文案都绝不超宽。

标准ESP-IDF构建、合并镜像及官方应用包校验通过。元数据见 [JSON](ui-polish-0.3.6.json)。本轮没有烧录真机，面板视觉和性能仍需真实设备确认。
