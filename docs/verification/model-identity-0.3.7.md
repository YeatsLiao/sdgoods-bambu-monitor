# X1C 型号识别修复 0.3.7

用户反馈：v0.3.6 画面效果已满意，实际打印机为 X1C，但界面仍显示 BAMBU。

## 修复范围

- 识别 OTA `product_name: Bambu Lab X1-Carbon`，统一显示 X1C；继续支持不带连字符的名称和 BL-P001。
- 订阅成功后后台查询型号，未识别时每6秒重试，最多3次；每次重连恢复查询预算，已识别就停止。
- 型号单独读取采用状态锁，不拷贝整份4400字节状态；日志记录查询次数和识别成功值。身份应答不再被误报为无有效遥测。
- 所有皮肤继续使用原有动态型号字段，沿用0.3.6布局和资源。

名称来源与边界见 [MQTT 型号规则](../architecture/mqtt-identity.md)。这里没有把型号写死为 X1C，也不通过 AMS 名称、主板版本或序列号猜测。

## 检查

实际 C 解析器回归通过：带连字符的真实应答结构识别为 X1C、后续遥测增量保持型号、身份不刷新遥测时间、不冒充配对成功、AMS 不能覆盖主机型号、重连清空旧身份、AP05 不被当作机型。

官方82文件与radio逐字节一致；文档、原图保留记录与资源镜像检查通过。

ESP-IDF 5.5.5 标准 `build`、`merge-bin` 和完整镜像组件校验通过，构建日志位于 `build/log/build-model-0.3.7.log`。

## 真机状态

COM6 可打开；被动监听12秒未捕获型号应答，未重启、未烧录。因此已证实名称兼容性缺陷，但尚未核对本用户机器返回的具体字段。

烧录后等待 MQTT 连接，查看首页/详情页及串口 `Printer model identified: X1C`。若打印机不返回可识别身份，继续显示 BAMBU；不要将软件测试通过当作本机识别成功。
